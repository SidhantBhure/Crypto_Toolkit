Classical Cryptography Toolkit

An interactive web-based application that demonstrates classical encryption and decryption techniques. Explore eight fundamental cipher algorithms, understand how they transform plaintext into ciphertext, and verify results with built-in decryption.

❓ Help & Guide

📖 How to Use This Toolkit

  • Select a cipher from the sidebar or click a card on the dashboard.
  • Choose Encrypt or Decrypt mode using the toggle.
  • Enter your text in the input field.
  • Enter the required key for the selected cipher.
  • Click Run to see the result.
  • The verification section shows the reverse operation to confirm correctness.
  • Use Swap to Input to copy the output back into the input for further operations.
  • Use Compare Algorithms to encrypt the same text with multiple ciphers at once.

🔒 What is Encryption?

Encryption is the process of converting readable text (plaintext) into an unreadable format (ciphertext) using a specific algorithm and a key. Only someone with the correct key can reverse the process.

Decryption is the reverse — converting ciphertext back into the original plaintext using the same key and the inverse of the encryption algorithm.

⚠️ Valid Input Requirements

  • Text Input: Enter any text. Most ciphers handle letters, spaces, and punctuation. Some (like Hill, Playfair) operate only on letters and will strip other characters.
  • Keys: Each cipher has specific key requirements. Invalid keys will display clear error messages.
  • Case: Caesar, Vigenère, Monoalphabetic, and One-Time Pad preserve letter case. Hill, Playfair output uppercase only.
  • Empty Input: An error message will be shown if you try to run an operation with empty text.

❓ Common Errors

  • "Key must be exactly 26 letters" — The Monoalphabetic key needs every letter A-Z exactly once.
  • "Matrix is not invertible mod 26" — The Hill Cipher key matrix determinant shares a factor with 26. Choose a different matrix.
  • "Key length must equal the number of letters" — The One-Time Pad key must have exactly as many letters as the input text (ignoring spaces/punctuation).
  • "Number of rails must be ≥ 2" — Rail Fence requires at least 2 rails.
  • "Ciphertext length must be even" — Playfair works in pairs; the ciphertext must have an even number of letters.

⚠️ Security Notice

This toolkit is an educational project designed to demonstrate classical cryptographic algorithms.

⚠️ Warning: Classical ciphers (Caesar, Vigenère, Playfair, Hill, etc.) are NOT secure by modern standards. They are vulnerable to frequency analysis, known-plaintext attacks, and brute-force methods. Do not use these ciphers for protecting sensitive or real-world data. Modern applications should use established cryptographic standards like AES, RSA, or TLS.
